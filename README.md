## REAPER Verify
- Sometimes REAPER takes a second to fully load, so if you are pretty sure that everything should be working,
but it is telling you it needs you to restart REAPER, hit cancel and try verifying again. Despite instructions,
if you can, open reaper before even launching this app to allow reaper to have enough time to fully boot.
